### 6.1 数据层补充

建议在 mock / ViewModel 中补充以下字段：

```js
{
  lastPurchaseAt: '2026-04-18',
  lastShipmentAt: '2026-04-25',
  estimatedArrivalAt: '2026-05-29',
  inboundSummary: {
    totalQty: 16,
    nextArrivalAt: '2026-05-29',
    fastestMethod: '空派',
    slowestMethod: '海派',
  },
  fbaInboundDetails: [
    {
      shipmentId: 'FBA18K4JP',
      dispatchOrderNo: 'SO-20260509-001',
      logisticsMethod: '空派',
      qty: 8,
      shippedAt: '2026-05-04',
      estimatedArrivalAt: '2026-05-19',
      status: 'shipped',
    },
    {
      shipmentId: 'FBA18K4JP-2',
      dispatchOrderNo: 'SO-20260509-002',
      logisticsMethod: '海派',
      qty: 8,
      shippedAt: '2026-05-02',
      estimatedArrivalAt: '2026-05-29',
      status: 'receiving',
    },

```

物流时效 mock 规则：

- 空派：约 15 天。
- 海派：约 25 天。
- 快递：约 8-10 天。
- 如同一 SKU 有多笔在途，预计到货时间默认展示最近一笔，hover/dropdown 展示全部。

### 6.3 AI 场景入口建议

| 场景 | 推荐入口文案 | 推荐输出结构 |
|-|-|-|
| 单 SKU 决策 | 这个 ASIN 还能卖多久？要不要补、补多少？ | 断货日、建议补货、海/空方案、风险说明。 |

## 8. 当前结论

当前版本已经修掉了工作台基础口径里的多数问题，但仍有三个会影响演示可信度的核心缺口：

1. 规则弹窗“销量预测”黑屏，是明确阻塞缺陷。
2. 采购计划生成后没有跳转到采购中心/草稿详情，动作闭环未完成。
3. 运营新增字段和 FBA 在途明细没有落到列表与详情页，数据解释链路不完整。

建议先按 P0 三项修复，再进入 AI 场景和视觉优化。
